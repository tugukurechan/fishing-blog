# 決めたこと

決めたことは消さずに追記する。変えたときは、変えた側の項目に理由を書き、元の項目に「D-xx で変更」と書く。

| ID | 項目 | 決めたこと | 理由 | 状態 |
|----|------|------------|------|------|
| D-01 | 作り方 | Next.js（App Router）の静的出力（`output: "export"`）で、記事ごと・ページごとに HTML を前もって作る。記事は `content/posts/*.mdx` に MDX で書き、先頭の frontmatter に釣果の項目を書く。サーバー・DB・ログインは持たない | 書くのは自分だけなので、投稿画面や DB は要らない。Markdown に慣れていて、特別なところだけ JSX と Tailwind のクラスでデザインできる。タグ・釣り場一覧・検索も、ビルド時にページや索引を作れば静的のまま作れる | **決定**（2026-10-21） |
| D-02 | 写真 | `npm run photos` で横幅1600px の WebP にし、メタデータ（位置情報を含む）を消してから `public/photos/<記事>/` に置く。元の写真は commit しない。テストで `public/photos` が WebP だけで EXIF・XMP がないことを確かめる | スマホの写真は数MBあり、撮影場所の GPS が入っている。git は消したファイルも履歴に残すため、commit の前に済ませる必要がある。1枚200〜400KB程度なら、200記事でもリポジトリと無料枠に収まる | **決定**（2026-10-21） |
| D-03 | 釣り場の書き方 | `spot` は「○○港」「○○川 河口」くらいの粒度にし、ポイントの細かい位置は書かない | 釣り場が荒れたり立入禁止になったりするのを防ぐ。写真の位置情報は D-02 で消す | **決定**（2026-10-21） |
| D-04 | 公開先 | Cloudflare に置き、`tugukurechan.com` のサブドメインにする。セキュリティヘッダーは `public/_headers` で付ける。Pages と Workers（静的ファイルの配信）のどちらにするかは、公開時点の Cloudflare の推奨と料金で決める | アフィリエイトや広告を載せる可能性があり、Cloudflare は無料のまま商用利用できる。ドメインも Cloudflare Registrar で買う予定で、DNS を1か所で管理できる。静的出力では next.config の headers() が使えない | **決定**（2026-10-21）。Pages / Workers は未決定 |
