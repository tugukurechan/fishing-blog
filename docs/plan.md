# 進め方

機能を増やしすぎず、書いて公開できる状態を先に作る。各段階は `feature/*` ブランチで作り、PR でマージする。

## Phase 1: 書いて読める

- [x] MDX の記事から一覧と記事ページを作る（D-01）
- [x] 釣果の項目の確認（書き間違いでビルドを止める）
- [x] 記事で使う部品: 釣果カード・写真・写真の2列
- [x] 写真の変換と、位置情報が残っていないかの検査（D-02）
- [ ] ブログの名前を決める（`src/lib/site.ts`、リポジトリ名）
- [ ] 最初の記事を書き、見本の記事（`sample-trip`）を消す

## Phase 2: 探せる

- [x] タグ（`tags`）と一覧の写真（`cover`、なければ本文の最初の写真）・本文の書き出し
- [x] 一覧の絞り込み（魚種・釣り場・タグ・年）。条件は URL に持つ（D-06）
- [x] 記事の検索（ビルド時に `/search.json` を作り、検索を使ったときだけ読み込む）
- [ ] 魚種・釣り場ごとの個別ページ（例: `/fish/シーバス`）。検索エンジンから来てもらいたくなったら作る

## Phase 3: 見た目と共有

- [ ] デザインを整える（トップ・記事・スマホ表示）
- [ ] ファビコンと OGP 画像（LINE や X で記事を送ったときのプレビュー）
- [ ] sitemap.xml と robots.txt

## Phase 4: 公開

- [ ] Cloudflare に置く（D-04。Pages / Workers を決める）
- [ ] `tugukurechan.com` を取得し、サブドメインを付ける
- [ ] ポートフォリオ（`tugukurechan.com`）から、ikokka と並べてリンクする
